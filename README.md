# Favorite Habits  

## Описание  
Favorite Habits - сервис своевременного оповещения пользователя о наступлении определенных событий.  
Пользователь регистрируется, получает на указанную электронную почту письмо со ссылкой на
подключение к телеграм-боту, переходит по ссылке и таким образом его телеграм-аккаунт связывается
с его аккаунтом в приложении. В приложении пользователь описывает свои привычки - действия, о которых
он хотел бы получать напоминания, и указывает расписание, когда должно приходить уведомление. При наступлении
указанного момента времени пользователь получает сообщение в свой телеграм с напоминанием выполнить определенное действие.  

## Запуск

Для запуска локального сервера разработки выполните в терминале команду:  
git clone git@github.com:havaikrab/Favorite_Habits.git  
Заполните файл .env необходимыми переменными в соответствии с шаблоном .env_template  
Выполните в терминале команду docker compose up -d  
API-интерфейс станет доступен в вашем браузере  

Для запуска сервера с постоянным IP-адресом разместите на машине в рабочей директории содержимое директории /deploy  
Заполните .env-файл соответствующими переменными  
Выполните в терминале команду docker compose up -d  
API-интерфейс станет доступен в глобальной сети  

## Примечания

Версия локальной разработки работает на базе стандартного django сервера, в то время как в
контейнере продакшен-версии используется nginx сервер.  
Возможные ограничения api.telegram могут вызвать сбой в работе телеграм-бота, отправляющего
сообщения пользователям. Однако это не влечет за собой прекращение работы сервера Favorite Habits
