Для тестирования вебхуков, рекомендуется использовать любой сервис,
наподобие ngrok или serveo, позволяющий создавать ssh-тоннели для сервера разработки.  
В режиме разработки, в переменных окружения (файл .env) Ключи DBUG и USE_TEST_WEBHOOK должны иметь значение True,
а ключ TEST_WEBHOOK_PATH содержать ссылку на сервер, предоставляющий тоннель.  
Запустите сервер разработки и один из упомянутых сервисов в отдельных терминалах, но с указанием одного,
и того же порта, сохраните адрес, предложенный сервисом в переменных окружения в ключе TEST_WEBHOOK_PATH.
Сервер готов для тестирования.  
В продакшен-версии, при развертывании сервера в глобальной сети под собственным постоянным
IP-адресом необходимо установить ключ DEBUG равным False, в указании TEST_WEBHOOK_PATH
нет никакой необходимости.
